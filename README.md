# Төлеген Бауыржан — персональный сайт

Статический сайт-резюме на трёх языках (KZ / RU / EN) с PDF-версиями резюме.

## Файлы
- `index.html` — сайт (один файл, без сборки)
- `tolegen-bauyrzhan-cv-ru.pdf`, `-kz.pdf`, `-en.pdf` — резюме для скачивания

## Публикация
**GitHub Pages:** Settings → Pages → Source: *Deploy from a branch* → `main` / `root`.
**Vercel:** Add New → Project → импортируйте этот репозиторий, Framework: *Other*, без команды сборки.
